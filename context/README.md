# Context Manifest System

Компактные YAML-файлы — база знаний проекта для AI-агентов.  
**Цель**: агенты читают YAML вместо исходного кода → 3–5x меньше токенов, быстрее ответ.

## Правило сессии

```
Каждая сессия начинается с:
  1. context/project.yaml       — что за проект, фаза, tech stack
  2. context/roadmap.yaml       — что сделано, что в процессе
  3. context/modules/<модуль>.yaml  — только нужный модуль
Исходный код читается только если YAML недостаточно.
```

## Файлы

| Файл | Что описывает | Обновлять когда |
|---|---|---|
| `project.yaml` | Цель, tech stack, архитектура, текущая фаза | Смена фазы, новые интеграции |
| `interfaces.yaml` | Все TypeScript интерфейсы с полями и правилами | `types.ts` изменился |
| `env.yaml` | Все env-переменные: где используются, как получить | Новая переменная добавлена |
| `roadmap.yaml` | Статус каждой задачи P0–P6 | Задача выполнена/добавлена |
| `decisions.yaml` | Architecture Decision Records (ADR) | Новое архитектурное решение |
| `modules/scraper.yaml` | Файлы скрапера, экспорты, паттерны, known gaps | Новый скрапер, изменились контракты |
| `modules/n8n.yaml` | n8n воркфлоу, Ollama конфиг, маппинг Notion | Воркфлоу создан/изменён |
| `modules/ci.yaml` | GitHub Actions workflows, секреты, требования | Workflow изменён |
| `SYNC_PROTOCOL.md` | Правила синхронизации: что → что обновить | При добавлении нового правила |
